How to Use the Case Converter

1. Paste or type your text into the input box above. 2. Click the case format you want, from UPPERCASE to camelCase. 3. The output updates instantly as you type; click Copy Output to grab the converted text. The character and word counts update live, so it doubles as a quick word counter.

Worked example: paste hello world example and click Title Case to get Hello World Example. Click snake_case instead and you get hello_world_example. Paste an existing identifier like myVariableName and the tool splits it on the camelCase boundary first, so one click gives you my_variable_name or my-variable-name with no retyping.

Frequently Asked Questions

How do I change text from uppercase to lowercase?

Paste the text into the input box and click the lowercase button. The tool rewrites every letter at once, which is faster and less error-prone than retyping, especially for long passages.

What is camelCase?

camelCase writes a compound name with no spaces, lowercasing the first word and capitalizing each word after it, like myVariableName. It is the standard for variables and functions in JavaScript, TypeScript, and Java.

What is the difference between camelCase, PascalCase, and snake_case?

camelCase starts lowercase and capitalizes every word after the first (myVariable). PascalCase, also called UpperCamelCase, capitalizes every word including the first (MyVariable). snake_case writes everything lowercase with underscores between words (my_variable). Pick the one your language or style guide prefers: JavaScript uses camelCase for variables, classes use PascalCase, and Python uses snake_case.

When should I use snake_case vs kebab-case?

Use snake_case for Python, Ruby, and database column names. Use kebab-case for CSS class names, HTML attributes, and URL slugs. The choice usually follows the conventions of the language or framework you are working in.

What is CONSTANT_CASE used for?

CONSTANT_CASE (also SCREAMING_SNAKE_CASE) uppercases every letter and separates words with underscores, like MAX_SIZE. It is used for constants, environment variables, and enum values in many programming languages.

Does title case capitalize every word?

In formal title case (AP, Chicago, or APA style), small words like articles, short conjunctions, and short prepositions stay lowercase unless they start or end the title. This tool capitalizes the first letter of every word, which matches most headings but is not strict Chicago or AP style.

Can I convert code variable names between cases?

Yes. The converter splits the input on whitespace, underscores, hyphens, and camelCase boundaries before re-joining the words in the format you pick. Paste myVariableName and one click gives you my_variable_name, my-variable-name, MyVariableName, and every other style.

Is this case converter free?

Yes. It runs 100% in your browser, is free forever, and never sends your text to any server.
