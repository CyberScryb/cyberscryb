Distill — Privacy Policy

Last updated: April 16, 2026

The Short Version

Distill does not collect, store, or transmit any user data. Everything runs locally in your browser. There is no server, no analytics, no tracking.

What Distill Does

Distill is a Chrome extension that extracts article content from web pages and displays it in a clean, distraction-free reading view. All processing happens entirely within your browser using JavaScript.

Data Collection

Distill collects zero data. Specifically:

  • No personal information is collected
  • No browsing history is recorded
  • No page content is transmitted to any server
  • No cookies are set
  • No analytics or tracking scripts are used
  • No third-party services are contacted

Permissions

Distill requests the following browser permissions:

  • activeTab — To access the current page content when you activate Distill
  • storage — To save your preferences (theme, font size) locally in your browser
  • scripting — To inject the reading view overlay into the current page

These permissions are used solely to provide the reading mode functionality. No data leaves your browser.

Local Storage

Distill uses Chrome's local storage API to save your preferences (selected theme, font size, and on/off state). This data is stored locally on your device and is never transmitted anywhere.

Third-Party Services

Distill does not use any third-party services, APIs, or analytics platforms.

Changes to This Policy

If we ever change how Distill handles data, we will update this page and the "Last updated" date above.
