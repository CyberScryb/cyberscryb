## 2026-06-27 - [Direct Copy Access in Editors]
**Learning:** Developers value speed when working with multiple payloads. Providing a direct "Copy" action within code editors/output areas significantly reduces friction compared to manual highlighting, especially for large blobs of data like UUIDs or minified JSON.
**Action:** Always include a one-click copy button in components that display generated output or handle raw data payloads.
