Pictures for phrases

Each decode puzzle is a short string of emoji. It stands for a phrase, an idiom, a tech term, a proverb, or a story shape such as a time loop or a heist plan. The phrases are generic, public domain, or written for this page. There are no song lyrics and no film titles. The pictures are the emoji already on your device, so the page does not load an image for them.

Type what you think it says. Capital letters, extra punctuation, and the words a, an, and the do not change the result. A letter or two out of place in a longer word still counts. A different phrase does not. If you are stuck, Hint first shows the first letter of each word, then the word count. A third step, or Reveal, shows the answer. Each step lowers the points: 100 with no hint, 70 after the letters, 40 after the word count, and 0 if the answer is revealed. A clean run of solves builds a streak. A miss or a reveal sets it back to zero.

The same ten, on purpose

A round is 10 puzzles, so a perfect round is 1000. Daily mode does not call a server. This page hashes the UTC date and deals 10 puzzles from that number, so two people on the same UTC calendar day get the same order. A random round is a fresh shuffle. Play again on a daily date keeps the higher score for that date. The best score is the best round on this device, daily or random. The result you copy includes the emoji from the round and a row of marks: green for a clean solve, yellow when a hint was used, red for a miss.

A translator that stays on the page

Translate is the other mode. Type any sentence and the page swaps words it knows for emoji, using a few hundred common words and short phrases that ship with the file. A word it does not know stays as text, so the line is still readable. Copy takes that line. Nothing you type is written to storage. The screen-reader name for a puzzle, before you answer, is the emoji count and a level. It does not speak the solution.

Guesses disappear when you leave or deal again. This browser can keep the best total and the daily total, and Clear saved scores deletes both. If a later save fails, the status says this browser is not keeping the latest score.

FAQ

Does this upload my guesses or sentences?

No. Both modes run in your browser. The only things saved are your best score and the daily score for the UTC date you played, in this browser's local storage. Guesses and sentences are not stored and are not sent anywhere.

How close does a guess have to be?

Case does not matter. Extra punctuation is ignored. The words a, an, and the can be present or missing. A small typo in a word still counts. A different phrase does not.

How do hints change the score?

A solve with no hint is 100 points. The first hint shows the first letter of each word and caps the puzzle at 70. The next hint adds the word count and caps it at 40. Reveal shows the answer and scores 0. A miss or a reveal ends the streak.

What is daily mode?

Today's 10 is a fixed set of puzzles chosen from the UTC calendar date, computed in this browser. A friend who opens the game on that same UTC date gets the same puzzles in the same order. There is no server and no account. Play again on the same date keeps the higher daily score.

How does the translator work?

Translate uses a word list of a few hundred common words and short phrases that ships with this page. It never calls a network. Words with no emoji stay as text, and you can copy the line. The sentence is not saved.

Where do the best score and the daily score live?

Only in this browser. Clear saved scores deletes both. Clearing site data for cyberscryb.com removes them too. The game does not ask for an account, and leaving the page drops the current round.
