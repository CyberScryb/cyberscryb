## Directory Purposes

**`public/`:**

- Purpose: Firebase Hosting root. Every file here is served at cyberscryb.com
- Contains: All HTML pages, CSS, JS, images, fonts, robots.txt, sitemap.xml
- Key files: `index.html` (homepage), `tools.html` (tool grid), `css/style.css` (canonical styles)

**`public/tools/{tool-name}/`:**

- Purpose: One directory per tool, served at `/tools/{tool-name}/`
- Contains: `index.html` + one JS file per tool + optional tool-specific CSS
- Key example: `public/tools/summarizer/` — canonical template for new AI tools

**`public/tools/shared/`:**

- Purpose: JavaScript and CSS shared across all AI tool pages
- Contains: `ai-tool.js` (loaded by every AI tool), `email-capture.js` (passive bar), `affiliate-panel.js` (contextual recommendations)
- Loaded via: `<script src="../shared/ai-tool.js">` from within tool directories

**`public/guides/`:**

- Purpose: 21 SEO-optimized guide pages generated by `generate-pages.js`
- Contains: One HTML file per guide + `guide.css` + `index.html` listing
- Do NOT manually edit — regenerate by running `node generate-pages.js`

**`public/blog/`:**

- Purpose: Blog posts hand-authored (not generated)
- Contains: 5 blog posts + `index.html` listing
- Naming: `{topic}-{year}.html` (e.g., `how-to-write-a-hardship-letter-2026.html`)

**`functions/`:**

- Purpose: Firebase Cloud Functions backend
- Contains: Single `index.js` with all 4 functions and the `AI_PROMPTS` table
- Requires `npm install` before deploy (dependencies not committed to root)

**`generate-pages.js`:**

- Purpose: Build-time script to generate SEO guide HTML pages and `sitemap.xml`
- Run manually: `node generate-pages.js` from project root
- Writes to: `public/guides/` and `content-site/guides/`

## Key File Locations

**Entry Points:**

- `public/index.html`: Homepage — uses absolute paths (`/css/style.css`)
- `public/tools.html`: All-tools listing — uses absolute paths
- `public/tools/{name}/index.html`: Each tool page — uses `../../css/style.css`
- `public/guides/index.html`: Guides listing
- `public/blog/index.html`: Blog listing

**Configuration:**

- `firebase.json`: Hosting config, API rewrites, security headers, cache headers
- `.github/workflows/deploy.yml`: CI/CD pipeline definition
- `functions/package.json`: Cloud Functions dependencies

**Core Logic:**

- `functions/index.js`: All backend logic — AI dispatch, rate limiting, email capture
- `public/tools/shared/ai-tool.js`: All frontend AI tool behavior
- `generate-pages.js`: Guide generation script with all 21 page definitions

**Global Frontend:**

- `public/css/style.css`: Canonical stylesheet — all pages must load this
- `public/js/script.js`: Global JS — navbar, GA4 tracking, Cloudflare chatbot, CJ Affiliate

## Naming Conventions

**Tool directories:**

- Pattern: `kebab-case` matching the `toolId` used in `AI_PROMPTS`
- Examples: `hardship-letter/`, `email-writer/`, `json-csv-converter/`

**Tool JS files:**

- AI tools: `{tool-name}.js` (e.g., `summarizer.js`, `hardship-letter.js`)
- Older dev tools: `script.js` (e.g., `base64-tool/script.js`, `password-checker/script.js`)

**Blog posts:**

- Pattern: `{descriptive-slug}-{year}.html`
- Example: `how-to-write-a-hardship-letter-2026.html`

**Guide pages:**

- Pattern: `{slug}.html` where slug matches `pages[].slug` in `generate-pages.js`
- Example: `how-to-convert-json-to-csv-in-excel.html`

**Root pages:**

- Flat HTML files at `public/` root: `about.html`, `contact.html`, `privacy.html`, etc.

## Where to Add New Code

**New AI Tool (using `/api/ai-generate`):**

1. Add prompt to `AI_PROMPTS` in `functions/index.js` — key must match new `toolId`
2. Create `public/tools/{tool-id}/index.html` — copy from `public/tools/summarizer/index.html`
3. Create `public/tools/{tool-id}/{tool-id}.js` — call `CSAITool.init({ toolId: '{tool-id}', ... })`
4. Add tool card to `public/tools.html`
5. Add `<option>` to homepage dropdown in `public/index.html`
6. Add `<url>` entry to `public/sitemap.xml`
7. Commit and push — auto-deploys both hosting and functions

**New SEO Guide Page:**

1. Add a page object to the `pages[]` array in `generate-pages.js`
2. Run `node generate-pages.js` from project root
3. Commit the generated file at `public/guides/{slug}.html` plus updated `sitemap.xml`

**New Blog Post:**

1. Create `public/blog/{descriptive-slug}-{year}.html`
2. Follow existing blog post structure (deferred AdSense, nav with Blog link, footer)
3. Add card to `public/blog/index.html` listing
4. Add `<url>` to `public/sitemap.xml`
5. Commit and push

**New Global Style or Script:**

- CSS: Add to `public/css/style.css`
- JS: Add to `public/js/script.js` (for all pages) or a new file loaded only where needed
- Never add blocking `<script>` tags to `<head>` — load async or defer

**New Cloud Function endpoint:**

1. Add `exports.newFunction` to `functions/index.js`
2. Add rewrite to `firebase.json` under `hosting.rewrites`
3. Commit and push — GitHub Actions deploys both
